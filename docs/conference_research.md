## What this means for the Speaker Scout

1. **Speakers fill different roles.** Keynotes are well-known crossover voices. Panels are practitioners, executives and researchers. Moderators are often journalists. → Each card should say what the person is best suited for: **Keynote / Panelist / Moderator / Workshop leader**.
2. **Panels mix sectors around one theme** (the YBEC model). → The six categories fit well, and a later "build a balanced panel" feature would match how planners actually work.
3. **Profile level matters for budget and the odds of a yes.** Smaller summits book regional, mid-career experts, not celebrities. → Add a **profile level** (Rising voice / Established expert / Headliner) and an optional **location preference** (e.g. "Northeast US").
4. **Credentials show up in bios:** PhD, MD/MPH, certified arborist, books, awards. → Add a **credentials** line to the card.
5. **Past speaking predicts a yes.** Many of these people speak at several of these events. → The "Has spoken before" section is the right call.
6. **Conference type changes who's relevant** (business vs. philanthropy vs. practitioner vs. academic). → An optional **"conference type / audience"** field for the Scout Lead.
