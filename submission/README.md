# submission/

What goes on Canvas besides the repo link.

| File | Rules |
|---|---|
| `report.html` | Single self-contained HTML file, 10–15 printed pages, the 8 required sections in order, images embedded |
| `slides.html` | reveal.js from a CDN, 10 slides max, images embedded, same colors as the app |
| `images/` | Working copies of images before they are embedded |
